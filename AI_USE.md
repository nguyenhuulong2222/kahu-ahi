# Use of AI

This project's code, its documentation and the Kahu Ahi mark were made with an AI assistant (Claude, by Anthropic, in chat and through Claude Code), working to the team's requirements and under the team's review.

- **Code and documentation.** Written with the AI assistant and reviewed and run by the team. All project code was written after the hackathon started (14 Nov 2026, 9:00 AM HST). Before the hackathon, AI was used only to study the challenge statement, the participant rules and NASA FIRMS documentation and to plan the approach; no project code from before the hackathon is in this repository.
- **Numbers.** Every figure in the README and on the page comes from running the pipeline on NASA FIRMS data, not from the AI. An independent recomputation and its findings are in [AUDIT.md](AUDIT.md); that audit was also carried out with the AI assistant.
- **Images.** The Kahu Ahi mark (`docs/kahu-ahi-mark.svg`) and the link-preview image made from it (`docs/kahu-ahi-og.png`) were made with the AI assistant, as above. They carry no visible "AI-generated" watermark. No photograph, video or audio in this project was generated by AI; any added later will be listed here and carry a visible "AI-generated" watermark.
